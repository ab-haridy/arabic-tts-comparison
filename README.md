# تحويل النص إلى كلام بالعربية المشكولة: مقارنة بالسمع

الصفحة: https://ab-haridy.github.io/arabic-tts-comparison/

تجربة بالسمع لأربع أدوات تحويل النص إلى كلام: ElevenLabs v3، وHUMAIN Voice، وSILMA TTS v1، وHabibi TTS. السؤال: أيها ينطق الكلمات المشكولة والأصوات المفردة («مَـ»، «بْ») بدقة؟ وفي الصفحة 47 مقطعًا للاستماع، وما يناسب كل أداة، وطريقة تشغيل Habibi على الماك.

## المحتوى

- `index.html`: الصفحة كاملة، وبياناتها داخلها.
- `audio/`: المقاطع بصيغة mp3، واسم كل ملف `<النص>-<الأداة>.mp3`.

## العرض محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا بسيطًا:

```sh
python3 -m http.server 8000
```

ثم افتح http://localhost:8000.

## ملاحظات

- تجربة بحثية غير تجارية، لا صلة لها بأي من الشركات المذكورة.
- المقاطع أصوات مولّدة آليًا، وكل مقطع وفق شروط الأداة التي ولّدته. نص الصفحة وتصميمها تحت CC BY 4.0. التفاصيل في [LICENSE.md](LICENSE.md).
- ما كتبه whisper تحت كل مقطع فحص آلي تقريبي، والحكم الأخير بالسمع.
- الأدوات تتغير، والنتيجة كما كانت في نوفمبر 2026.
